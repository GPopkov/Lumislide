## Структура проекта (Swift Package, macOS 15+, Apple Silicon)

**Этап 0 — каркас:** `Package.swift` (3 модуля + 2 тест-таргета), Swift 6 tools / язык Swift 5.

**Этап 1 — `SlideStoryModel` (готова полностью):**
- `TransitionType` — 12 переходов, `TransitionPicker` (детерминированный SplitMix64 по seed)
- `SlideshowProject` — корень, seed строкой (без потери точности 64-бит), миграция при декодировании
- `MediaReference`, `FaceRegion`, `TitleOverlay` (кастомный Codable для SIMD4), `MusicSource` + `MusicTimelinePlanner` (фото-интервалы, fade 2 c)
- `ExportSettings`, `AspectRatio`, `ProjectStore`, `BookmarkResolver`, `DefaultProjectsDirectory`

**Этап 2 — `SlideStoryRenderer` (пайплайн реализован):**
- `KenBurnsPlanner` — детерминированные траектории, лица → точка интереса
- `TimelineBuilder` — раскладка с перекрытием на переходах, кламп перехода к слайду (E5)
- `SlideImageCompositor` — fit + blur-заливка + титр + KB единой трансформацией
- `TransitionBlender` + `Transitions.metal` — 7 CI-переходов, 5 Metal-кернелов
- `VideoFrameSource`, `SlideContextFactory`, `TimelineFrameRenderer` (кадр на момент времени)
- `SlideshowExporter` — двухпроходный экспорт: видео (AVAssetWriter) → аудио-микс → mux (H.264/H.265, прогресс, отмена)
- `AudioTrackMixer` — музыка только на фото-интервалах + собственные дорожки видео-слайдов, fade 2 c, зацикливание
- `FaceDetector` — Vision (только bounding box лиц, без идентификации)

**Этап 3 — `SlideStoryApp` (полный UI):**
- `LumislideApp` (@main), `AppSettings` (язык ru/en, папка, автосохранение, длительность фото)
- `ProjectsStore` (проекты, автосохранение, добавление медиа + Live Photo, **детекция лиц при добавлении**)
- `MainWindowView` + `ProjectListView` (список проектов слева)
- `ThumbnailGridView` (NSCollectionView + drag&drop reorder, ПКМ: переходы/титр/KB/relink/delete)
- `ThumbnailItem` (карточка: номер, миниатюра, значок, длительность, титр, рамка перехода)
- `ThumbnailCache` (дисковый кэш миниатюр, инвалидация по дате изменения)
- `L10n` (локализация строк ru/en — ~45 ключей, переключатель в настройках)
- `ProjectPropertiesView`, `TitleEditorView`, `PreviewWindowView` (живой рендер), `ExportWindowView`, `SettingsView`

**Релизный контур (этап 4):**

## Исправленные в ходе сборки ошибки
- `.macOS(.v15)` → swift-tools-version 6.0 + язык Swift 5
- `SIMD4<T>` → `SIMD4<Scalar>`; кастомный Codable титра
- `transitionOrder` перенесён в тип; переполнение Int в SplitMix64
- `AVMutableComposition` не хранит `audioMix`; `AVAssetWriterInputPixelBufferAdaptor` для CVPixelBuffer
- `standardized` (CGRect, не CGSize), `makeLibrary(source:options:)`, `CGPoint` для radial-градиента
- `AVAssetExportSession` (passthrough) для mux видео+аудио

## Важно для сборки на этой машине
Xcode установлен, но активный developer directory — Command Line Tools (там нет XCTest). Перед `swift test` задавайте:
`export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`
